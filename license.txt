without installing anything system-wide. Both are redistributed unmodified,
which is what keeps their reserved font names usable here.

  fonts/Raleway-v4020-Regular.otf

    Copyright 2010 The Raleway Project Authors (impallari@gmail.com),
    with Reserved Font Name "Raleway".
    Licensed under the SIL Open Font License, Version 1.1.
    Full text: fonts/Raleway-OFL.txt   Change history: fonts/Raleway-FONTLOG.txt

    These are the official static builds released by the Raleway project
    (github.com/impallari/Raleway, fonts/v4020), copied byte for byte. They
    are NOT modified versions, so clause 3 of the OFL — which forbids a
    modified version from using the reserved font name — is not engaged.
    If you ever regenerate them, do not cut static instances out of the
    variable font and keep calling them "Raleway": instancing counts as a
    modification under the OFL and the name would then have to change.
